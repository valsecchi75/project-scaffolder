# Todo — project notebook

> The inbox of everything not planned yet. One line per item, never deleted; closing changes the mark and appends the outcome. Report: `/todo`. Planned work lives in `wiki/priorities.md` and the milestone plans.

Format: `- [ ] T-NNN | P1|P2|P3 | feedback|idea|debug|debt|question|doc | YYYY-MM-DD | <one actionable sentence> | from: <source>`
Marks: `[ ]` open · `[>]` planned `| -> M<n> a<k>` · `[x]` done `| -> done <date>: <evidence>` · `[-]` dropped `| -> dropped: <reason>`
